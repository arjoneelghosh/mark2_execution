# mark2_execution

Clean execution baseline for the portfolio site.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS

## Local setup

```bash
npm install
npm run typecheck
npm run build
```

## Notes

- The Ask experience uses bundled local knowledge loaded from `src/data/content` and `src/data/docs`.
- Ongoing light mode work continues from the `light_mode_exec` branch.
